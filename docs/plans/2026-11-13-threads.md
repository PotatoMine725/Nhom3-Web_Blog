# Plan: Thread theo chủ đề

- Ngày: 2026-11-13
- Branch: `feature/threads` (tạo từ `dev`)
- Spec liên quan: `specs/01` (BR12–BR14), `specs/02` (UC08, UC09, UC21–UC25), `specs/03` (Thread, ThreadMember, Post.thread, index, logic), `specs/04` (route, view), `specs/05` bước 12
- Đáp ứng: UC21, UC22, UC23, UC24, UC25, phần chọn thread của UC08, UC09, BR12, BR13, BR14

## Mục tiêu

Thành viên tạo thread theo chủ đề, tham gia / rời thread và đăng bài vào thread đã tham gia. Mọi người xem được danh sách thread, trang thread và bài trong thread; bài trong thread vẫn hiện ở trang chủ, tìm kiếm, ... kèm nhãn thread.

## Ngoài phạm vi

- Thread riêng tư, duyệt thành viên, mod trong thread, sửa thông tin thread, chuyển quyền người tạo, thông báo (spec 01).
- Trang danh sách thành viên của thread (chỉ hiện số thành viên).
- Trang admin riêng cho thread: admin xoá thread ngay ở trang thread.
- Thống kê thread ở `/admin` (spec 03 không thêm truy vấn thống kê).
- Không thêm thư viện mới.

## Các bước

1. **Model** — file: `src/models/Thread.js`, `src/models/ThreadMember.js`, `src/models/Post.js`.
   - `Thread`: `name`, `slug`, `description`, `tag`, `author` theo spec 03, `timestamps: true`. Hook `pre('validate')` chép từ `Category` (chặn tên trùng không phân biệt hoa thường bằng regex đã escape, sinh slug, trùng thì `-2`, `-3`), thêm điều kiện `slug === 'new'` coi như đã dùng (giống Post), slug rỗng thì `'thread'`.
   - `ThreadMember`: `user`, `thread` bắt buộc, `timestamps: { createdAt: true, updatedAt: false }`, index unique `{ thread: 1, user: 1 }`, index `{ user: 1 }` (chép cấu trúc `Bookmark`).
   - `Post`: thêm `thread: { type: ObjectId, ref: 'Thread', default: null }` và index `{ thread: 1, status: 1, createdAt: -1 }`. `readForm` không đọc `thread` (đọc riêng như `category`).
2. **threadController** (mới) — file: `src/controllers/threadController.js`.
   - `index` (UC21): `page` như trang chủ, 10 thread/trang, sort `{ createdAt: -1, _id: -1 }`, populate `author`. Hai aggregation theo spec 03 (đếm thành viên, đếm bài `published`) cho các id trong trang, gắn `memberCount`, `postCount`. Đã đăng nhập thì `ThreadMember.distinct('thread', { user })` để gắn `joined`.
   - `showNew`, `create` (UC23): đọc `name`, `description`, `tag` (trim; `tag` lowercase), `author` từ session. Lưu lỗi validate thì render lại form 400. Lưu xong tạo `ThreadMember` cho người tạo; lỗi thì `Thread.deleteOne` rồi `next(err)`. Flash "Đã tạo thread", redirect trang thread.
   - `show` (UC22): tìm theo slug, không có thì 404. Đếm thành viên, `isMember`, bài `{ thread, status: 'published' }` phân trang 10 bài, populate `author`, `category`, `thread`, gắn `commentCount` (dùng lại hàm đếm bình luận đang có, export từ `postController` nếu cần).
   - `join` (UC24): thread không có thì 404; `ThreadMember.create`, lỗi 11000 bỏ qua; redirect trang thread.
   - `leave` (UC24): người tạo thì flash lỗi "Người tạo không thể rời thread"; còn lại `deleteOne`; redirect trang thread.
   - `remove` (UC25, `req.doc` do `requireOwnerOrAdmin` nạp): `ThreadMember.deleteMany`, `Post.updateMany({ thread }, { thread: null }, { timestamps: false })`, `deleteOne`; flash "Đã xoá thread", redirect `/threads`.
3. **Route** — file: `src/routes/threads.js` (mới), `src/app.js` (thêm 1 dòng `app.use('/', threadRoutes)`). Khai báo `/threads/new` trước `/threads/:slug`. `remove` dùng `requireOwnerOrAdmin((req) => Thread.findOne({ slug: req.params.slug }))`.
4. **postController: chọn thread** — file: `src/controllers/postController.js`.
   - `readThread(value, authorId, currentThreadId)`: `''` → `null`; bằng `currentThreadId` → giữ nguyên, không kiểm (bài vẫn sửa được sau khi tác giả rời thread / admin sửa); id sai, thread không tồn tại hoặc tác giả bài chưa có `ThreadMember` → `undefined` (báo "Bạn chưa tham gia thread này").
   - `create`: `readThread(req.body.thread, currentUser._id, null)`. `update`: `readThread(req.body.thread, post.author, post.thread)`. Xử lý `undefined` giống cách đang làm với `category` (đưa về `null` để render lại form, gọi `reject`).
   - `renderForm`: nhận thêm `threads` = thread tác giả bài đã tham gia (`ThreadMember.find({ user }).populate('thread', 'name')`, bỏ thread `null`), cộng thread hiện tại của bài nếu không có trong danh sách. `values.thread` luôn là chuỗi id (`''` = không thuộc thread). Mọi chỗ gọi `renderForm` truyền `authorId` để nạp danh sách.
   - `showNew`: có `?thread=<slug>` và user đã tham gia thì chọn sẵn; không thì bỏ qua.
   - Thêm `.populate('thread', 'name slug')` ở mọi truy vấn danh sách / chi tiết bài: `postController` (`renderShow`, `index`, `show`, `popular`), `searchController.renderList`, `reactionController.bookmarks`, `commentController.create` (render lại trang bài khi lỗi).
5. **View** — file: `src/views/threads/index.ejs`, `show.ejs`, `form.ejs` (mới), `src/views/posts/form.ejs`, `src/views/posts/show.ejs`, `src/views/partials/post-card.ejs`, `src/views/partials/left-nav.ejs`.

   - `post-card`, `posts/show`: nhãn thread (link `/threads/<slug>`) khi `post.thread && post.thread.name`, kiểu giống `category-chip`.
   - `left-nav`: mục "Threads" sau "Nổi bật", tô đậm khi `currentPath` bắt đầu bằng `/threads`.
   - Nút xoá thread: form POST + `onsubmit="return confirm(...)"` giống nút xoá bài đang có.
6. **Test** — file: `tests/threads.test.js` (cần MongoDB, không có thì skip), copy cấu trúc `like-bookmark-popular.test.js`. `clearDb` xoá mọi collection nên không cần sửa `helpers.js`. `views.test.js` tự biên dịch 3 view mới.
